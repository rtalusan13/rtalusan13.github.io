Logos used inline in text (class="inline-logo").

uiuc-block-i.svg
  The University of Illinois Block I, used in the hero line on index.html.
  Download the official file from the university's brand site
  (brand.illinois.edu) and save it here with this exact name.
  Until the file exists, the page shows the text "UIUC" instead.

Any other logo: save it here, then use
  <img class="inline-logo" src="assets/logos/FILE" alt="Name">
SVG is best (sharp at any size). PNG works too: export it at least 64 px tall.
