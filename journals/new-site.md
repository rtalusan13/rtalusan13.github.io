My portfolio used to live on Google Sites. This site replaces it, with more room for the parts I care about: the hardware I build and what I learn along the way.

## What's here

- **[Resume](../resume.html):** experience at Raytheon, teaching and research at UIUC, coursework, and skills. There's a PDF there too.
- **[Projects](../projects.html):** write-ups of my work, from a two-player game suite running on an FPGA system-on-chip to a RISC-V operating system I'm building now.
- **Journal:** this page. Shorter notes that don't fit on a resume.

## How it's built

The site is plain HTML, CSS, and JavaScript on GitHub Pages, with no framework. The resume, the projects, and these journal entries are Markdown files that the pages read and render in the browser, so keeping things current is a one-line edit and a push.

## What I'll write about

Things I'm learning in ECE coursework, notes from FPGA and verification projects, and lessons from working as a systems engineer, within what I can share.
